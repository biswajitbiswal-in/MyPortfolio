## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 20.9 or later)
- `npm` or `pnpm`

### Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/biswajitbiswal-in/MyPortfolio.git
   cd MyPortfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Configure Environment Variables:**
   Copy the example environment file:
   ```bash
   cp .env.example .env.local
   ```
   *(Optional) Add your Resend API key in `.env.local` to enable the contact form:*
   ```env
   RESEND_API_KEY=your_resend_api_key_here
   ```

4. **Run the Development Server:**
   ```bash
   npm run dev
   ```

5. **Open in Browser:**
   Visit [http://localhost:3000](http://localhost:3000) to view your 3D portfolio!
